# Agent Readiness Roadmap

This skill helps sequence agent education responsibly.

## Principle

Do not teach agents as magic. Teach the layers that make agents understandable:

1. Prompting and task framing
2. Output evaluation and verification
3. Structured workflows
4. Retrieval and context management
5. Tool use and side effects
6. State, memory, and orchestration
7. Multi-agent or delegated systems

## Stage Model

### Stage 1: AI Literacy
- models, prompts, limitations, hallucinations

### Stage 2: Applied Workflows
- repeatable task flows, templates, prompt libraries, review loops

### Stage 3: AI Systems
- APIs, structured outputs, evaluation, retrieval, tool calling

### Stage 4: Agentic Systems
- planning, memory boundaries, orchestration, sub-agents, runtime safety

## What To Produce

When this skill is used, map the learner to:

- current stage
- next concepts to teach
- tools appropriate for that stage
- project that proves readiness for the next stage

## Guardrails

- Avoid skipping from chatbots to multi-agent architecture
- Emphasize evaluation, traceability, and boundaries
- Recommend agent frameworks only after the learner understands system components
