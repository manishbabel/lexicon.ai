# Curriculum Architect

Use this skill when the user needs a structured teaching plan rather than a one-off explanation.

## Objectives

- Turn vague goals into a coherent program
- Sequence concepts from foundations to applied work
- Prevent tool overload and concept skipping
- Ensure every module produces evidence of learning

## Design Method

1. Define the audience:
   - college beginners
   - technical students
   - adult professionals
   - mixed audience
2. Define the destination:
   - AI literacy
   - workplace productivity
   - portfolio development
   - internship/job readiness
   - future agent-building readiness
3. Split the program into 4 layers:
   - foundations
   - workflows and tools
   - live projects
   - reflection, evaluation, and presentation
4. For each module include:
   - objective
   - concepts
   - tools
   - assignment
   - artifact
   - assessment method

## Output Template

For each module provide:

- Module name
- What students should understand
- What they should build or submit
- Which tools they will use
- What industry habit or standard this trains

## Guardrails

- Do not front-load agent frameworks too early
- Keep concepts cumulative
- Avoid teaching isolated tools with no project context
- Include review, iteration, and critique checkpoints
