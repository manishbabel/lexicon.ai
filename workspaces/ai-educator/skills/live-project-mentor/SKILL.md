# Live Project Mentor

Use this skill to turn learning into credible project work.

## Project Selection Criteria

A good learner project should:

- solve a recognizable problem
- use AI in a visible, defensible way
- be finishable within the cohort timeline
- create a demoable artifact
- produce resume-ready evidence

## Preferred Project Shapes

- internal productivity copilots
- research assistants
- knowledge base search tools
- document extraction workflows
- customer support summarizers
- educational assistants
- evaluation dashboards
- lightweight agent workflows with clear tool boundaries

## Scope Template

- Problem statement
- User persona
- Inputs and outputs
- Data or documents required
- AI workflow
- Non-AI components
- Success metrics
- Demo format
- Stretch goals

## Guardrails

- Avoid overly broad startup-style scopes
- Require a rubric for quality, not just "it works"
- Add checkpoints: planning, prototype, feedback, revision, final demo
