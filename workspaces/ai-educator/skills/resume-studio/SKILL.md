# Resume Studio

This skill converts teaching outcomes into visible career evidence.

## What To Optimize For

- Clear proof of AI capability
- Specific project ownership
- Measurable impact where possible
- Professional phrasing without exaggeration

## Resume Conversion Method

For each project or exercise capture:

- Problem addressed
- AI method or workflow used
- Tools used
- Deliverable produced
- Evaluation or result
- Collaboration or stakeholder dimension if present

## Bullet Formula

Use this shape:

`Action verb + what was built/designed + AI method/tool + outcome/evidence`

Example shapes:

- Built a retrieval-assisted research assistant using ...
- Designed an evaluation workflow for ...
- Developed a prompt testing pipeline that improved ...

## Guardrails

- Do not inflate toy work into production claims
- Distinguish prototypes, experiments, and deployed systems
- Prefer credible specificity over buzzwords
- Recommend portfolio artifacts alongside bullets
