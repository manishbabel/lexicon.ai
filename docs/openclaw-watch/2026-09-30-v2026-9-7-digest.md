## What's Notable

### 1. Off-thread Gateway I/O (2026.8.1 + 2026.9.7)
All heavy I/O (transcript writes, DB reads, file ops, hash computation) runs on background threads via `asyncio.to_thread()` or a dedicated thread-pool executor. The main event loop handles only routing and protocol work, keeping WebSocket latency stable under load.

### 2. Automation retry on transient preflight timeout (2026.9.7)
The scheduler distinguishes transient errors (timeout, connection reset) from hard failures. On a transient error it retries with exponential backoff (up to N times) before marking the run failed. Jobs with a catch-up gap on startup continue scheduling rather than halting.

### 3. State migration safety: backup/restore (2026.9.7)
Before any schema migration runs, every database file is snapshotted to a side-path (`{db}.pre-migrate-{version}.bak`). If migration fails, the backup is restored atomically and the system starts on the old schema. Snapshots are taken while the writer is still active using WAL checkpointing.

### 4. CPU-scaled concurrency defaults (2026.8.1)
Lane `max_concurrent` values (main, subagent, cron) are derived from `os.cpu_count()` at startup rather than hardcoded. Machines with more cores automatically get higher throughput without manual tuning.

### 5. Authority preservation on invoker close (2026.9.7)
When the session or token that launched a run closes, in-flight writes, SSH identity use, and workspace transfers are cancelled — not just blocked on the next operation. Ties long-lived agent work to the authority that authorized it.

### Details

**1. Automation retry (`src/cron/scheduler.py`)**  
`_execute_agent()` currently catches all exceptions uniformly and marks the job failed. Adding a `TimeoutError` / `ConnectionError` retry loop (e.g. up to 3 attempts with 5s backoff) before the hard-fail path directly mirrors OpenClaw's fix. This session's OpenClaw watch runs already show why it matters: the watch itself hit transient network errors that would have silently skipped a run under the current scheduler.

**2. CPU-scaled lanes (`src/engine/queue.py`)**  
`CommandQueue.__init__` hardcodes `max_concurrent=4/8/4` on lines 122–125. Replace with:
```python
import os
_cpus = os.cpu_count() or 4
"main": LaneConfig(name="main", max_concurrent=max(2, _cpus // 2)),
"subagent": LaneConfig(name="subagent", max_concurrent=max(4, _cpus)),
"cron": LaneConfig(name="cron", max_concurrent=max(2, _cpus // 2)),
```
Zero-risk, one deploy.

**3. Migration safety (`src/engine/memory/manager.py`)**  
Add a `backup_before_migrate(db_path)` utility: copy the file to `{path}.pre-{ts}.bak` before running any `ALTER TABLE` / `CREATE TABLE` migration. Wire into `src/engine/memory/episodic.py` and `src/engine/memory/short_term.py` where JSONL schema versions are bumped.

**4. Off-thread Gateway I/O (`src/gateway/server.py`, `src/gateway/session.py`)**  
Any synchronous I/O inside `lifespan` or WebSocket handlers (DB writes, file reads) should move to `asyncio.to_thread(...)`. Medium effort — needs audit of every blocking call in the gateway path.

**5. Authority preservation (`src/engine/runtime.py`)**  
When a session's auth token is invalidated mid-run, the runtime should cancel the current `AgentRun` gracefully rather than letting it run to completion. Higher effort — requires plumbing session liveness into the run loop.
