## What's Notable (Patterns Worth Tracking)

**1. Crash-loop repair state machine (Gateway)**
OpenClaw 7.1 replaced unbounded gateway restart loops with a structured repair path: on N consecutive failures, the gateway enters a "needs-repair" state and halts auto-restart, surfacing a clear recovery action. This prevents runaway restart storms from masking the root cause.

**2. Wake-on-change scheduling (Cron)**
Scheduled jobs now check a digest of their input state before executing. If nothing changed since the last run, the job records a skip and returns immediately. This halves unnecessary LLM invocations for polling-style cron jobs and makes logs dramatically easier to read.

**3. MCP session-scoped tool isolation (Tools)**
Previously, MCP server connections were shared across all sessions on a gateway. 7.2-beta.3 scopes each connection to the requesting session. This prevents tool-result bleed between concurrent agent sessions and makes authorization boundaries meaningful at the session level.

**4. Compaction instruction preservation (Memory/Context)**
Context compaction in 6.11 was updated to detect repeated system instructions (e.g., personality, tool definitions) and carry them forward verbatim rather than summarizing them away. Summaries previously dropped these, causing agents to lose role anchoring mid-conversation.

**5. Credential log scrubbing (Shared/Logger)**
7.1 added an active scrubbing pass on log output that detects token-shaped and password-shaped strings and replaces them with `[REDACTED]`. Applied at the logger sink, not at each call site.

## What We Can Use in Lexicon (Ranked)

### 1. Credential log scrubbing — `src/shared/logger.py`
**Value: High | Effort: Low**
Lexicon's logger currently emits raw kwargs. Adding a scrubbing filter at the `logging.Handler` level (regex on known patterns: `Bearer \S+`, `api_key=\S+`, `password=\S+`) closes an accidental-secret-leak vector at a single point. Straightforward to spike in an afternoon.

### 2. Compaction instruction preservation — `src/engine/context/compactor.py`
**Value: High | Effort: Low-Medium**
Lexicon's compactor summarizes message windows without distinguishing system instructions from user content. Port OpenClaw's pattern: before summarizing a window, extract messages with `role=="system"` or matching known instruction prefixes and append them verbatim after the summary. Prevents personality/tool-definition drift in long sessions.

### 3. Wake-on-change scheduling — `src/cron/scheduler.py` + `src/cron/store.py`
**Value: High | Effort: Medium**
Lexicon's scheduler fires every tick unconditionally. Port OpenClaw's input-digest approach: each job defines a `change_key()` function; the scheduler stores the last key in `src/cron/store.py` and skips execution if the key is unchanged. Reduces LLM cost and log noise for `defaults.py`-style monitoring jobs.

### 4. MCP session-scoped isolation — `src/engine/tools/registry.py`
**Value: Medium | Effort: Medium**
The tools registry currently holds a single shared tool set per gateway. Scoping MCP connections to session ID (keyed on the session object from `src/gateway/session.py`) would prevent tool-result cross-contamination in concurrent sessions. Requires passing session context into `src/engine/tools/registry.py` at registration time.

### 5. Gateway restart circuit breaker — `src/gateway/server.py`
**Value: Medium | Effort: Medium-High**
Add a consecutive-failure counter to `src/gateway/server.py`. After N restarts in a window, stop auto-restarting and set a `NEEDS_REPAIR` flag exposed via a health endpoint. Prevents silent crash loops from consuming resources and makes failures visible to operators.
